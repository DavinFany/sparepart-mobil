Disarankan

Login dengan password

Mode login aktif. Di HP atau laptop mana pun, cukup buka /admin.html, masukkan password, lalu klik Publikasikan. Website otomatis diperbarui, tanpa upload manual.

Atur sekali saja di Vercel. Setelah itu, cukup masukkan password untuk publikasi otomatis dari perangkat mana pun.

  1. Buat token GitHub. Caranya ada di kotak "Cara membuat token" di bawah (langkah 1–5).
  2. Buka vercel.com, lalu pilih project website ini, lalu Settings → Environment Variables.
  3. Tambahkan GITHUB_TOKEN dengan nilai token tadi.
  4. Tambahkan ADMIN_PASSWORD dengan password pilihan Anda untuk masuk panel admin.
  5. Buka tab Deployments, klik ⋯ pada deployment teratas, lalu pilih Redeploy.
  6. Muat ulang halaman ini. Layar login akan muncul.

Cara lain: token di perangkat ini

Dengan terhubung, tombol Publikasikan langsung memperbarui website (Vercel memperbarui otomatis dalam ±1 menit). Data koneksi hanya disimpan di browser ini.

Cara membuat token

  1. Login ke GitHub, buka Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klik Generate new token. Beri nama, mis. "Admin Toko", dan atur masa berlaku.
  3. Di Repository access, pilih Only select repositories lalu pilih repo website ini.
  4. Di Permissions → Repository permissions, ubah Contents menjadi Read and write.
  5. Klik Generate token, salin token, lalu tempel di form sebelah.

Jangan bagikan token kepada siapa pun. Jika HP/laptop hilang, hapus token di GitHub.

Tanpa koneksi / cadangan
